# 🎄 动态圣诞树 Merry Christmas

抖音同款 **粒子发光圣诞树** 动态网页,纯 HTML + CSS + JavaScript 单文件实现,零依赖、无需联网。

## ✨ 效果

- 🌈 约 700 个发光粒子按黄金角螺旋排成圆锥,自动旋转 + 随风摆动
- 🎨 色彩循环流动、随机闪烁,夹杂红金"彩球"粒子
- ⭐ 树顶大星星:呼吸光晕 + 旋转光芒 + 环绕小亮点
- ❄️ 漫天雪花 + 背景闪烁星空 + 雪地光晕
- 🎆 点击屏幕绽放烟花
- 🖱️ 拖动鼠标手动旋转圣诞树(松手后自动恢复慢转)
- 🔔 右上角按钮播放 WebAudio 实时合成的《铃儿响叮当》(无需音频文件)
- ⏳ 自动计算圣诞倒计时

## 🚀 使用

直接用浏览器打开 `christmas-tree.html` 即可,手机/电脑均适配。

## 🛠️ 技术

单文件 Canvas 2D 渲染,发光粒子使用按色相预生成的径向渐变贴图 + `lighter` 叠加混合,保证流畅 60fps。
